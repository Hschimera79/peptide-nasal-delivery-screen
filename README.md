# peptide-nasal-delivery-screen

A computational workflow to prioritize desmopressin analogues for
intranasal delivery, based on physicochemical descriptors and
enzymatic stability.

## Why desmopressin
Desmopressin is a cyclic nonapeptide analogue of vasopressin, already
marketed as a nasal spray. Its reported intranasal bioavailability
(~3-5%) gives this pipeline a real-world reference point.
